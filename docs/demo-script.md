# Three-minute demo

1. Generate the corpus, open the application, and select a system disengagement case.
2. Play the -10 s to +5 s replay; point out the alert at the red disengagement marker.
3. Run triage. Explain that numerical evidence routes the case before the LLM summarizes it.
4. Add a perception or safety-expert note. Mark it as a simulated persona to demonstrate developer persona testing.
5. Open the candidate rule, run regression, and approve it as the system owner if it passes.
6. Show the activity timeline and knowledge-graph provenance as the audit trail. Configure Slack/Ambiguous credentials to mirror the final event in a real workspace.
